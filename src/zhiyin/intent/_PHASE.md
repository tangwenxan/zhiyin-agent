# [S4] 意图识别与路由 —— 本目录你要写什么

**目标**：先"听懂"再"分派"。

## 要实现的文件
- `router.py`：
  1. 定义意图类别：`chitchat / knowledge_query / task / emotion / unsafe`
  2. 用 LLM（few-shot）做分类，返回 `{intent, confidence}`
  3. 按意图路由到不同处理路径（RAG / Planner / 兜底 / 安全拒答）
  4. 低置信度时走澄清追问

## 动手步骤
1. 先用 LLM + few-shot 跑通分类，构造 20 条测试用例测准确率。
2. 再接路由表，把意图映射到处理函数。
3. （加分）后续用微调小模型替换，对比准确率与成本。

## 验收标准
- [ ] 20 条测试集上意图准确率 ≥ 85%
- [ ] 路由后各分支都能正确触达
- [ ] 对 `unsafe` 有明确拒答策略

## 常见坑
- 一上来就微调，没有 few-shot 基线做对比
- 不输出置信度，无法兜底
