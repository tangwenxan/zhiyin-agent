# [S6] Durable Execution + 沙箱 —— 本目录你要写什么

**目标**：任务跨进程/跨天可靠跑完；工具在受控环境执行。

## 要实现的文件
- `durable.py`：**先自研轻量版**
  - 任务状态机：`pending / running / waiting / done / failed`
  - 每步执行前写 checkpoint 到数据库
  - 服务启动时扫描未完成任务并续跑（**replay 已完成的步骤，不重复执行**）
  - `sleep_until(t)`：持久化定时，支撑"3 天后回访"
  - 所有副作用调用带**幂等键**
- `sandbox.py`：`run_sandboxed(code)`
  - 子进程隔离 + 超时 + 内存/CPU 限制 + 输出截断 + 网络白名单
  - （进阶）替换为 Docker 容器隔离

## 动手步骤
1. 自研状态机 + checkpoint，跑通"3 天后触发"。
2. 杀掉进程重启，验证任务继续且不重复执行。
3. 加幂等键，验证重试不会重复发帖。
4. 加沙箱，写"超时用例"和"越权用例"各一个。
5. （可选）替换为 Temporal / DBOS，写对比笔记。

## 验收标准
- [ ] 长任务跨进程可恢复、幂等
- [ ] 沙箱能拦截超时与越权
- [ ] 一份"自研 vs 成熟框架"对比文档（面试高光）

## 常见坑
- 以为"加个重试"就是持久化（难点在跨进程恢复 + 幂等）
- 沙箱只做超时，不做资源/网络限制
- 太早上 Temporal，陷进运维而没理解原理
