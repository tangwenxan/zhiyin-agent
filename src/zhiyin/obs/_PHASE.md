# [S8] 可观测 —— 本目录你要写什么

**目标**：能看清一个请求从进来到出去的**完整调用树**（LLM 调用、工具调用、耗时、token、成本）。

## 要实现的文件
- `tracing.py`：接入 **Langfuse**
  - 用环境变量初始化（见 `.env.example`）
  - 给一次会话打 trace，给每次 LLM / 工具调用打 span
  - 把意图、检索结果、记忆命中、最终回答都挂到 trace 上

## 动手步骤
1. 注册 Langfuse，拿到 key 填进 `.env`。
2. 在 `llm.py` / `registry.py` 的关键调用处接入装饰器打点。
3. 跑几次对话，在 Langfuse 看板上查看 trace 树。
4. 截图存档，作为简历/博客素材。

## 验收标准
- [ ] 能看到一次请求的完整调用链与成本
- [ ] 出问题时能靠 trace 定位是哪个环节坏了

## 常见坑
- 只打日志不做结构化 trace
- 打点太细导致噪音，看不出主链路
