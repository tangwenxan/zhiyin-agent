# [S2] RAG 检索增强 —— 本目录你要写什么

**目标**：让 Agent 基于社区知识库带引用地回答问题，并把检索效果调到最优。

## 要实现的文件
| 文件 | 内容 |
|---|---|
| `chunking.py` | 切分策略：固定/递归/语义切分；实现**父子块**（小块检索、大块喂模型） |
| `ingest.py` | 流水线：加载样例数据 → 切分 → 向量化 → 写入向量库 |
| `retrieve.py` | 基础向量检索 + **BM25 稀疏检索** + **RRF 融合** |
| `rerank.py` | 用 BGE 或 Cohere 对候选做 **cross-encoder 重排**，取 top-k |

## 动手步骤
1. 用 `data/sample_posts.json` 跑通 ingest。
2. 纯向量检索问答，跑通第一版。
3. 依次叠加：混合检索 → RRF → 重排，**每加一步记录指标变化**。
4. 实现带引用作答（答案标注 `[来源#id]`）。

## 验收标准
- [ ] ingest 一条命令可重建索引
- [ ] 能带引用回答社区问题
- [ ] 有"纯向量 vs 混合 vs 加重排"的 Hit@5 对比数据

## 常见坑
- 只做纯向量检索就收工（2026 基线是混合检索 + 重排）
- 切分尺寸拍脑袋，不做对比实验
- 没有测试集，无法判断是否真的变好
