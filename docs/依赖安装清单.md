# 依赖安装清单（按阶段按需安装）

> 为什么不是一次性全装？
> 一是一次装几十个包很慢、很占空间；二是不同库之间容易版本冲突，一旦冲突
> `uv sync` 会直接报 "No solution found when resolving dependencies"，
> 而这时你根本不知道是哪个包引起的。**按需安装，出问题好定位。**

所有命令都在项目根目录（`D:\agent_project\zhiyin-agent`）执行。

## 排错速查

| 现象 | 原因 | 解决 |
|---|---|---|
| `No solution found when resolving dependencies` | 某个包名写错 / 版本范围冲突 | 先 `uv remove <可疑包>` 缩小范围；或把该包挪到真正需要时再装 |
| 装完某个包后整个 `uv sync` 失败 | 新包与已有包版本冲突 | `uv tree` 看依赖树，`uv add "包名<版本上限"` 约束版本 |
| `uv sync` 很慢 | 一次装太多 / 网络慢 | 国内加镜像：`$env:UV_DEFAULT_INDEX="https://pypi.tuna.tsinghua.edu.cn/simple"` |
| 报 Python 版本不符 | 缺 3.11+ | `uv python install 3.11`，然后 `uv sync --python 3.11` |
| 想推倒重来 | 环境装乱了 | 删掉 `.venv` 和 `uv.lock`，重新 `uv sync` |

> 记住：**`uv.lock` 可以随时删掉重建**，它只是依赖快照，不是你的代码，删了不心疼。
